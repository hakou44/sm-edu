# SM éducation v2.1.6

## v2.1.6 — تشغيل سكريبت جلب تسنيم من داخل التطبيق

- في مكتبة تسنيم قسم جديد «🔄 تشغيل سكريبت جلب تسنيم (للمشرف)»: زر لجلب كل المستويات وزر للمستوى المفتوح فقط، مع عرض حالة التشغيل وتحديث الفهرس تلقائياً عند النجاح.
- السكريبت يعمل على GitHub Actions (يحتاج خادماً متصلاً بالإنترنت، والمتصفح لا يستطيع جلب تسنيم مباشرة بسبب CORS). التطبيق يطلق سير العمل فقط ويتابعه.
- الإعداد مرة واحدة: أنشئ مفتاح GitHub «Fine-grained» لمستودعك وحده بصلاحية **Actions: Read and write**، والصقه في القسم. يُحفظ على الجهاز فقط ولا يُرسل إلا إلى `api.github.com`.
- لا يبدأ تشغيل جديد إذا كان آخر تشغيل ما زال جارياً. التفاصيل: `V2.1.6_RELEASE_REPORT.md`.

## v2.1.5 — جلب كامل للدروس والامتحانات والتمارين وحلولها

- سير نشر المحتوى يجلب الآن الاختبارات والفروض والدروس وسلاسل التمارين وحلولها بصيغتي PDF وWord، بحد 400 ملف لكل مستوى ولكل فئة وحجم أقصى 25 MB للملف.
- حفظ الفهرس والملفات وحالة الاستئناف حتى عند توقف الجلب بعد 300 دقيقة، فتستمر الدورة التالية من حيث توقفت.
- تحديث دليل النشر بملاحظات الحجم. التفاصيل: `V2.1.5_RELEASE_REPORT.md`.

## v2.1.4 — فحص شامل للمشروع وإصلاح الأخطاء

- الخدمة (Service Worker): حذف تكرار `styles.css`، وتخزين `curriculum-2026-2027.json` مسبقاً للعمل دون اتصال، ومفتاح تخزين جديد.
- إزالة قاعدة `parents.sqlite3` الفارغة من الحزمة (تُنشأ تلقائياً وهي مستثناة في `.gitignore`).
- تصحيح التوثيق: JDK 21 لبناء Android، وحد 120 ملفاً لكل مستوى في سير النشر.
- التفاصيل: `V2.1.4_RELEASE_REPORT.md`.

## v2.1.3 — نشر المحتوى ومزامنة مكتبة تسنيم

- توحيد اسم التطبيق الظاهر إلى SM éducation في واجهة الويب وبيانات PWA وCapacitor.
- إضافة مركز تنزيل يحفظ نسخاً تعليمية HTML مع التصحيحات في IndexedDB ويعرضها داخل التطبيق، مع خيار حفظ الملف على الجهاز.
- إضافة مسار روبوتيك مستقل ومتاح لجميع السنوات ضمن فضاء الذكاء الاصطناعي والحوسبة.
- إضافة `publicContentBase` لتوحيد عنوان HTTPS العام لموجز الدروس وفهرس تسنيم وملفات PDF/Word.
- إضافة تحديث يدوي لفهرس تسنيم داخل التطبيق، مع حفظ آخر فهرس ناجح واستعماله عند انقطاع الشبكة.
- إضافة دروس قابلة للمزامنة عن هندسة أوامر الذكاء الاصطناعي وسلامة النماذج الروبوتية.
- إضافة GitHub Actions لنشر المحتوى على GitHub Pages وإعادة فهرسة مكتبة تسنيم أسبوعياً بعد إذن صاحب الموقع، مع حدود للطلبات وحجم الموقع.
- راجع `CONTENT_FEED_DEPLOYMENT_AR.md` لإعداد Pages مرة واحدة؛ النشر الفعلي يحتاج مستودع GitHub الخاص بالمالك.

## ملاحظات تشغيل
- مكتبة تسنيم تقرأ الفهرس المحلي أو الفهرس المنشور، وتحمل ملفات PDF/Word عبر HTTPS وتحفظها في IndexedDB وتعرض PDF في عارض داخلي. لا تفتح صفحة المصدر في المتصفح.
- لتفعيل التحديث البعيد على APK، اضبط `publicContentBase` في `web/config.js` على عنوان GitHub Pages الفعلي ثم أعد بناء التطبيق. لم يتم نشر الموقع من بيئة التطوير لعدم توفر حساب/مستودع GitHub.
- تنزيل ملفات HTML المدروسة يعمل عبر آلية تنزيل WebView/المشاركة المتاحة في الجهاز؛ المعاينة والحفظ المحلي داخل التطبيق لا يحتاجان متصفحاً خارجياً.
